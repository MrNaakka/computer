ISA

registers on 0r 2r 3r ... 15r

opcode output input1 input2 constant
[31-28][27-24][23-20][19-16][15-0]

opcode:

0. 0000 = load
1. 0001 = load-high

2. 0010 = add
3. 0011 = substract
4. 0100 = isEqual
5. 0101 = isLessThan
6. 0110 = and
7. 0111 = or
8. 1000 = not

9. 1001 = write
10. 1010 = read

11. 1011 = jump to instruction, if condition
12. 1100 = jump to instruction always
13. 1101 = -
14. 1110 = -

15. 1111 = stop


instructions:
(opcode output input1 input2 constant)

load output - - constant
load-high output - - constant

add output input1 input2 -
substract output input1 input2 -
isEqual output input1 inpu2 -
isLessThan input1 inpu2 output -
and input1 inpu2 output -
or input1 input2 output -
not input1 inpu2 output - (input1 must be the same as input as the point is: (!a) | (!b) = !(a | b) = !a = !b)

write - address input2 -
readFrom ouput adderss - -

jmpc - - condition address
jmpa - - - adderss

stop - - - -


group 1 (ALU):
opcode operator = (aluOperator, in1SS, in2SS, eqSS)

add=add, 0, 0, 0
sub=add, 0, 1, 0
lt=less, 0, 1, 0
eq=add, 0, 1, 1
and=and, 0, 0, 0
or=or, 0, 0, 0
not=and, 1, 1, 0

so we need control signals for the aluoperator, in1SS, in2SS and eqSS.

output: alu output


group 2 (LOAD)
load: creates new word: take the 16 bits and then add 16 zero bits to create a 32bit word. 

output: the output from the above


group 3 (LOAD-HIGH)
load-high: take the current "lowest" 16 bits of the output register, with those and then the new bits create new 32 bitword.

output: output from the above



group 4 (write)

so we just write to the specified address the value in input2!

output: no output.



group 5 (read)

so we just read from the specified address.

output: the output from above.



group 6 (jump (move to instruction))

if the jump opcode is specified, then:
- take the bit 0 of the condition register, then use that as the selector signal for a mux between current instruction address +1 and the new specified address.
else:
- just the instruction address + 1.


- control signals: if the jump opcode is specified or not.

group 7 (halt)
if halt, then stop everything.

general contorl signals:
- from groups 1, 2, 3, 5, we need to decide which gets the output.
    - also when one of these is executed then the load signal for the specified register should be 1, else 0.
